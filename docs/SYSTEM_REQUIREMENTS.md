# ⚡ BYTE BLASTER — Системные требования

> Игра является 2D-платформером на HTML5, упакованным в Electron.
> Не использует 3D, WebGL или шейдеры — только 2D Canvas API.
> Запустится на любом ноутбуке после 2015 года.

## Уровни качества графики

Качество определяется **автоматически** при первом запуске по числу ядер CPU, объёму ОЗУ и мини-бенчмарку Canvas. Изменить вручную — **Настройки → Качество графики**.

| Уровень | Процессор | ОЗУ | Видеокарта |
|---|---|---|---|
| 🔴 **Очень низкое** | Любой двухъядерный 1.6+ ГГц | 2 ГБ | Любая |
| 🟠 **Низкое** | Двухъядерный 2.0 ГГц | 4 ГБ | Intel HD 3000 |
| 🟡 **Среднее** | Четырёхъядерный 2.4 ГГц | 4 ГБ | Intel HD 4000 / AMD Radeon HD 6000 |
| 🟢 **Высокое** *(по умолчанию)* | 4 ядра 3.0 ГГц | 8 ГБ | Intel UHD 620 / GeForce MX150 |
| 🔵 **Очень высокое** | 6 ядер 3.4 ГГц | 16 ГБ | GTX 1050 / RX 560 |
| ⚡ **Ультра** | 8 ядер 3.6+ ГГц | 16+ ГБ | GTX 1660 / RX 5500 |

## Если игра лагает

1. **Настройки → Качество графики** — снизить на одну ступень
2. **Лимит FPS → 60** — безлимитный FPS перегревает GPU
3. Закрыть фоновые приложения (OBS, браузер, рендер видео)
4. На ноутбуке — подключить зарядку: в режиме батареи GPU троттлится
