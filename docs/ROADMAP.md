## 🥇 Уровень 1 — дешёвое, но сильно меняет ощущение

### 1.1 Ежедневный уровень (seed дня)
Один общий для всех игроков процедурный уровень в сутки, seed = дата. Таблица
результатов внутри уже существующего relay-сервера. Это **самая дешёвая причина
заходить каждый день** — генератор уровней уже написан, нужен только фиксированный
seed и хранение рекорда.
*Стоимость: 1–2 дня. Даёт: ежедневный возврат.*

### 1.2 Реиграбельность существующих 110 уровней
Сейчас пройденный уровень не даёт повода вернуться. Добавить на карту мира
per-level челленджи: пройти без урона / собрать все кристаллы / уложиться в
время / не выстрелив ни разу. Отдельная иконка на узле карты.
*Стоимость: 2–3 дня. Даёт: ×2–3 к времени в игре без единого нового уровня.*

### 1.3 Реплеи призраков
Записывать вход игрока (это уже фиксированный 60 Гц, детерминированная физика и
seed по номеру уровня — то есть достаточно писать нажатия) и показывать призрак
своего лучшего прохождения. Дальше — призрак друга.
*Стоимость: 2–3 дня. Даёт: соревнование с собой, база для лидербордов.*

### 1.4 Экран статистики — ✅ СДЕЛАНО в 1.2.0
Вошёл в профиль оператора вместе с достижениями и архивом логов. Заодно добавлен
учёт наигранного времени, которого в игре не было.

## 🥈 Уровень 2 — новый контент на существующих системах

### 2.1 Мир 12 «Архив» — уровни-головоломки
Не боевой мир: механики уже есть (кнопки, двери, конвейеры, ключи, прожекторы),
но они почти не используются как головоломка. 10 уровней без врагов, где нужно
думать, а не реагировать. Хорошо ложится на сюжет (архив памяти GRID).
*Стоимость: 1–2 недели. Даёт: смену темпа, повод для тех, кому тяжёл экшен.*

### 2.2 Ещё две стихии к огню и льду
Огонь и лёд теперь полноценные механики (костюм, растрескивание, толкание,
иммунитеты). По той же схеме просятся:
- **Электричество** — цепной разряд между врагами, парализует, взаимодействует с
  водой/льдом;
- **Гравитация** — притягивает предметы и врагов, ломает блоки сверху.
Иммунитеты уже описаны таблицей — расширяется без переписывания.
*Стоимость: 1 неделя на стихию. Даёт: глубину боя на всех 110 уровнях сразу.*

### 2.3 Мини-боссы в середине мира
Сейчас босс только на 10-м уровне мира. Мини-босс на 5-м (укороченный бой,
одна механика) выровняет темп десятиуровневого блока.
*Стоимость: 3–5 дней на всех. Даёт: ритм внутри мира.*

### 2.4 Кастомизация робота — частично сделано в 1.2.0
Выбор аватара (11 персонажей) уже есть в профиле. Осталось главное: **привязать
часть скинов к звёздам и кристаллам**, чтобы у накопленных наград появилась цель.
*Стоимость: 2–3 дня. Даёт: смысл собирать звёзды.*

## 🥉 Уровень 3 — крупное

### 3.1 Редактор уровней + обмен уровнями
Самая большая по отдаче и самая дорогая идея. Генератор уровней уже строит
уровень из описания — редактору нужен UI и формат сохранения. Обмен — через тот
же relay-сервер, кодом уровня (как коды комнат).
*Стоимость: 3–6 недель. Даёт: бесконечный контент чужими руками.*

### 3.2 Соревновательный мультиплеер
Сейчас сеть — кооп. На той же базе: гонка по уровню на время, «царь горы»,
выживание с общим таймером.
*Стоимость: 2–3 недели. Даёт: причину играть с друзьями повторно.*

### 3.3 Roguelike-забег
Один забег = случайная цепочка уровней, между ними выбор из трёх улучшений
(дальше стреляешь / дольше горит / двойной прыжок ×3). Смерть = конец забега.
Использует существующий генератор и режим Infinite как основу.
*Стоимость: 2–3 недели. Даёт: режим с высокой реиграбельностью.*

## 🔧 Техническое, что стоит сделать до крупных фич

1. **Автотесты в CI.** Стенд из `BUGS.md` (100 уровней, прохождение, боссы,
   стихии) уже написан и ловит регрессии — стоит запускать его на каждую сборку,
   а не вручную.
2. **Мультиплеер под автотест.** Единственная крупная система без покрытия;
   любая правка сети сейчас проверяется только руками.
3. **Реальное устройство для Android.** Профиль снимается только на десктопе;
   бюджет кадра на слабом телефоне неизвестен.
4. **Steam App ID.** Код интеграции готов и просто не подключён — это блокер
   релиза, а не разработки.

## Чего я бы НЕ делал

- **Новые миры ради количества.** Их уже 11, а причин перепройти старые нет —
  сначала пункт 1.2.
- **Онлайн-экономику и внутриигровые покупки.** Игра премиальная и
  одиночная в основе; это меняет её жанр, а не улучшает.
- **3D / смену движка.** Текущий рендер укладывается в бюджет кадра и работает
  на трёх платформах; переписывание съест месяцы без выигрыша для игрока.
