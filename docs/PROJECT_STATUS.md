## Что есть сейчас

### Игра
- 100 уровней в 10 тематических мирах + секретный 11-й мир **Prism Anomaly**
  (уровни 101–110), открывается сбором 10 радужных осколков.
- 11 боссов, у каждого свой `weaknessType` (прыжок / выстрел / фазы / щиты…).
- Режимы: Adventure, Hardcore, Infinite, локальные 2 игрока.
- Мультиплеер до 5 игроков через relay-сервер на Railway + встроенный
  LAN-релей на `ws://localhost:3000` для режима LOCAL.
- Карта мира на canvas: один мир за раз, орбитальная раскладка узлов, дороги,
  ходьба робота между узлами, прогрессия открытия.
- Катсцены, достижения, 3 слота сохранений, звёзды и кристаллы за уровень.
- Профиль оператора: аватары, позывной, звания, статистика, архив логов.
- Статус-эффекты от врагов (горение, обледенение, ЭМИ, коррозия).
- Демо-редакция как отдельный вариант сборки.
- Локализация: **50 языков, покрытие 100%** (982 ключа в каждом), всё через
  `t()` и файлы `assets/localisation/*.json`. Подробности:
  [LOCALISATION.md](LOCALISATION.md).
- Аудио: mp3-сэмплы поверх процедурного синтеза (Web Audio).

### Поверх сети (аккаунт Pixset Studio)
- Единый аккаунт: лицензия на всех устройствах, вход по почте или по нику,
  облачные сохранения. Подробности: [ACCOUNTS.md](ACCOUNTS.md).
- **Уровень дня**: пять слотов, общий сид по UTC, суточная таблица
  ([DAILY_LEVEL.md](DAILY_LEVEL.md)).
- **Призрак лучшего забега**: свой рекорд, лидер дня или лидер уровня
  ([GHOST.md](GHOST.md)).
- Таблицы рекордов в трёх охватах: мир, страна, друзья.
- Продажа игры через ЮKassa — код готов, приём платежей ждёт подключения
  ([PAYMENTS.md](PAYMENTS.md)).

## Что осталось до релиза в Steam

### 🔴 Обязательно
1. **Регистрация в Steamworks** — $100, налоговая анкета, App ID.
   Инструкция: `STEAM_SETUP.md`, шаги 1–2.
2. **Подключить greenworks** с реальным App ID, создать `steam_appid.txt`,
   завести 45 достижений в панели Steamworks. Шаги 3–5.
3. **Графические материалы** для страницы магазина: капсулы (460×215,
   231×87, 616×353, 600×900), Library Hero 3840×1240, логотип с прозрачностью,
   5+ скриншотов 1920×1080, иконки достижений. Шаг 8.

### 🟡 Желательно
4. Ручной прогон мультиплеера на 2–5 клиентах (host + guest, реконнект,
   синхронизация врагов по стабильным ID).
5. Прогон Android-сборки на реальном телефоне: тач-раскладка, выход из APK,
   производительность на слабом устройстве.
6. Трейлер 30–60 сек.

### 🔵 Опционально
7. Таблица лидеров, Steam Trading Cards, настройки доступности.

## Диагностика проблем у игроков

Игра пишет `byte-blaster-log.txt` рядом с .exe (или в userData, если папка
не доступна на запись) — перезаписывается при каждом запуске.

| Симптом | Что смотреть |
|---------|--------------|
| Чёрный экран | строку `[render] tier N`; если тир 0 — попросить запустить с `--safe-mode` |
| Игра не стартует | последний `[checkpoint]` в логе — он показывает, на каком скрипте всё встало |
| Нужен профайлинг памяти | запустить с `--mem-log` |
| Сбросить режим рендеринга | запустить с `--reset-render-mode` |
