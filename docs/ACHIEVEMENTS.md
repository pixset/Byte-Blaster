## Интеграция в код

Добавить в `index.html` после инициализации:

```javascript
// Steam Achievements Integration
const ACHIEVEMENTS = {
  unlockAchievement(id) {
    if (window.steamAPI && window.steamAPI.isAvailable()) {
      window.steamAPI.unlockAchievement(id).then(result => {
        if (result.success) {
          console.log(`✓ Achievement unlocked: ${id}`);
          // Show in-game notification
          showAchievementNotification(id);
        }
      });
    } else {
      // Fallback for non-Steam version
      console.log(`[Local] Achievement: ${id}`);
    }
  }
};

// Примеры вызовов:
// После прохождения мира 0:
// ACHIEVEMENTS.unlockAchievement('achievement_world_0');

// После победы над боссом:
// ACHIEVEMENTS.unlockAchievement('achievement_boss_' + worldIndex);

// После сбора 1000 монет:
// if (totalCoins >= 1000) ACHIEVEMENTS.unlockAchievement('achievement_coin_1000');
```
