# 👤 Аккаунт, лицензия и всё, что поверх сети

Единый аккаунт Pixset Studio открывает купленную игру на всех устройствах и
держит на себе рекорды, друзей, бейджи и облачные сохранения.

Код в игре: `assets/license.js` (лицензия и вход), `assets/account-ui.js`
(кабинет), `assets/cloudsave.js`, `assets/friends.js`, `assets/leaderboard.js`,
`assets/profile.js`.

Сервер — Supabase, проект `zyjhvuhovimorpokiwty` (eu-central-1). Схема БД и
Edge Functions живут в репозитории сайта студии.

---

## Главный принцип: игра запускается без интернета

Сервер выдаёт **подписанный токен прав** (Ed25519). Подпись проверяется локально
через Web Crypto — никакого обращения к сети при запуске.

| Параметр | Значение |
|---|---|
| Срок токена | 90 дней |
| Отсрочка офлайн | ещё 30 дней после истечения |
| Итого без сети | около четырёх месяцев |

Упавший сервер не должен ломать честно купленную игру — отсюда такая щедрость.

Приватная половина ключа лежит **только** в секрете `LICENSE_PRIVATE_KEY`
(Supabase → Edge Functions → Secrets). Публичная зашита в `license.js` и в
`sdk/pixset-license.js` на сайте: при смене ключа менять обе половины сразу.

Никаких внешних зависимостей: `supabase-js` тянется с CDN и в офлайне (Electron,
Android в самолётном режиме) просто не загрузился бы. Поэтому в игре свой
маленький клиент на `fetch`.

## Где хранится

| Ключ | Что |
|---|---|
| `pixset.license` | подписанный токен прав |
| `pixset.session` | сессия входа |
| `pixset.clock` | отметка часов — против перевода системного времени назад |
| `pixset.device` | метка устройства |
| `pixset.avatar` | аватар для кнопки аккаунта |
| `pixset.authfail` | счётчик отказов обновить сессию |

По умолчанию это `localStorage`. Оболочка может подменить хранилище на
защищённое через `License.setStorage`: в `.exe` это `safeStorage` Electron (см.
`assets/persist-login.js` и `main.js`), в Android — Capacitor Preferences.

**Почему в .exe вход дублируется в файл.** Обновление приложения меняет папку
установки, и `localStorage` уезжает вместе с ней — игрока выбрасывало из
аккаунта после каждого апдейта. Теперь сессия лежит ещё и в
`userData/pixset-login.dat`, который обновление не трогает.

**Счётчик `pixset.authfail`** нужен, чтобы одна неудачная попытка обновить
сессию не разлогинивала: выход происходит только со второй подряд.

## Вход

Два способа:

* по **почте** — обычный вход Supabase Auth;
* по **нику** — Edge Function `login-nick` (без `verify_jwt`).

Функция принимает ник и пароль, находит почту на сервере и сама выполняет вход.
Почта наружу не отдаётся, а отказ всегда одинаковый (`invalid_credentials`) —
иначе по разнице ответов можно было бы перебирать существующие ники.

## Лицензии

Права выдаёт Edge Function `entitlements`: она собирает список купленных игр и
подписывает его. Игра проверяет подпись и работает дальше офлайн.

Источники лицензии (`licenses.source`):

* покупка — заказ через ЮKassa (см. [PAYMENTS.md](PAYMENTS.md));
* промокод — код на игру, погашенный в кабинете;
* выдача студией вручную — пока приём оплаты не включён.

### Временный доступ

У лицензии может быть срок: `licenses.expires_at`. Такие лицензии приходят от
промокодов вида «игра на N дней». Устроено это так:

* истёкшие лицензии не попадают ни в витрину `my_entitlements`, ни в ответ
  `entitlements` — их отсекает сам запрос;
* **срок токена укорачивается до ближайшего истечения**. Без этого недельный
  доступ работал бы все 90 дней: игра верит подписанному токену до последнего
  дня и в сеть не ходит;
* в токене у каждой лицензии есть `valid_until` — `null` значит «навсегда»;
* **офлайн-запас на срочные лицензии не распространяется**. 30 дней отсрочки
  придуманы для купленной игры: упавший сервер не должен её отнимать. К доступу
  по промокоду тот же запас был бы подарком — недельный код работал бы больше
  месяца, стоило не выходить в сеть. Поэтому `dropExpired` в `license.js`
  выбрасывает из прав всё, у чего свой срок уже вышел;
* покупка поверх временного доступа обнуляет срок: вебхук пишет
  `expires_at: null`.

Проверяется это при запуске игры и при обновлении прав, а не по таймеру: если
срок вышел посреди уровня, игрок доигрывает сессию спокойно, а закрывается
доступ со следующего запуска.

## Охваты таблиц рекордов

Таблицу можно смотреть в трёх охватах:

| Охват | Кто попадает |
|---|---|
| 🌍 Мир | все |
| 🏳 Страна | те, у кого в профиле указана та же страна |
| 👥 Друзья | только подтверждённые друзья |

Страна берётся из профиля; если игрок её скрыл, в страновой таблице он не
появляется — об этом прямо написано в подсказке (`scopeCountryHint`).

Смысл охватов простой: обойти пятерых знакомых интереснее, чем не обойти никого
в мире.

## Блокировки

Бан хранится в `profiles` (`banned_at`, `banned_until`, `ban_reason`). При входе
игра показывает причину и срок. Купленные лицензии при этом не пропадают:
одиночная игра остаётся доступной, даже если закрыт доступ к сетевым
возможностям.
