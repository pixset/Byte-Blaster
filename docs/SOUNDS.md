# 🔊 SOUNDS — Byte Blaster

> Полный список звуковых эффектов (SFX) игры.

## Как устроены звуки сейчас

Как и музыка, **все звуковые эффекты генерируются процедурно** через **Web Audio API** — реальных аудиофайлов в проекте нет. Библиотека эффектов — объект `SFX` в `index.html:622–653`.

### Базовые «кирпичики» звука (`index.html:584–620`)

| Функция | Сигнатура | Что делает |
|---------|-----------|-----------|
| `tone(freq, type, dur, vol, dst, detune)` | один тон | осциллятор фикс. частоты с быстрой атакой и экспоненциальным затуханием |
| `sweep(f0, f1, type, dur, vol, dst)` | глиссандо | осциллятор, плавно меняющий частоту от `f0` к `f1` |
| `noise(dur, vol, dst)` | шум | буфер белого шума с затуханием (удары, шаги, взрывы) |

- `type` — форма волны: `square`, `sawtooth`, `triangle`, `sine`.
- `dst` — узел назначения. Для SFX по умолчанию `SG` (SFX-гейн), для музыки — `MUG`.
- Громкость SFX управляется слайдером **SFX Volume** (`assets/settings.js`) через узел `SG`.

## 🎚 Маршрутизация и громкость

```
осциллятор/шум → SG (SFX gain) → MG (master gain) → AC.destination
музыка          → MUG (music gain) → MG → AC.destination
```

- `SG.gain` ← слайдер **SFX Volume** (1–100%)
- `MUG.gain` ← слайдер **Music Volume** (1–100%)
- `MG.gain` ← общий mute (кнопка 🔊/🔇, `toggleAudio` в `index.html:730`)

Настройка громкостей: `applyAudioVolumes()` (`index.html:558–571`), UI — `assets/settings.js`.

## 🔧 Если захотите заменить SFX на реальные сэмплы

1. Сложить `.wav` / `.ogg` в `assets/audio/sfx/`.
2. Предзагрузить в `AudioBuffer` и проигрывать через `AudioBufferSourceNode`, **подключая к узлу `SG`** — тогда слайдер SFX и общий mute продолжат работать.
3. Сохранить имена методов `SFX.jump()`, `SFX.coin()` и т.д. — вызовы по всему коду менять не придётся, достаточно переписать тело методов.
4. Для коротких частых звуков (выстрел, монета, шаг) держать буферы в памяти и создавать новый `BufferSource` на каждый вызов (источники одноразовые).

> Промтов для генерации SFX здесь нет намеренно — короткие ретро-эффекты проще и стабильнее делать в **jsfxr / sfxr / ChipTone / Bfxr**, чем в музыкальных AI-моделях. SUNO предназначена для музыкальных треков (см. [MUSIC.md](./MUSIC.md)).
