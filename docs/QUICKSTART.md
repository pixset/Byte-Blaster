# 🚀 Быстрый старт — Byte Blaster

> Обновлено 26 июля 2026 (версия 1.0.4). Прошлая версия этого файла описывала
> проект как «структура создана, впереди 25 багов» — это состояние мая 2026,
> задолго до релиза 1.0.0. Ниже — реальное состояние.

## Запуск за 30 секунд

```bash
npm install
npm start
```

Откроется Electron-окно с игрой. Никаких дополнительных шагов не нужно.

Хочешь просто в браузере — `npm run build:html` и открой
`dist/Byte Blaster (HTML)/index.html`.

## Структура проекта

```
Game/
├── index.html              # разметка, оверлеи, порядок загрузки скриптов
├── main.js                 # Electron: окно, рендер-тиры, IPC, LAN-релей, Steam
├── preload.js              # мост renderer ↔ main (contextIsolation)
├── local-server.js         # встроенный relay для режима LOCAL (ws://localhost:3000)
├── build-steam.js          # сборка .exe (список исключений для asar)
├── build-html.js           # сборка веб-версии
├── assets/
│   ├── game.js             # ядро: физика, уровни, враги, боссы, отрисовка
│   ├── worldmap.js         # карта мира (canvas, узлы, дороги, прогрессия)
│   ├── network.js          # мультиплеер до 5 игроков
│   ├── settings.js         # настройки + адаптивное качество графики
│   ├── touch.js/.css       # виртуальный геймпад для мобилок
│   ├── profile.js          # профиль: аватар, ник, статистика, достижения, архив
│   ├── logarchive.js       # каталог катсцен для вкладки «архив»
│   ├── i18n-new.js         # загрузчик локализаций
│   ├── localisation/       # 39 языков, по файлу на язык
│   └── audio/              # mp3-сэмплы (Music, SFX)
├── build/                  # build.bat, android-build.ps1, set-version.js
├── icons/                  # иконки приложения
└── docs/                   # эта документация
```

## Куда смотреть при правках

| Задача | Файл |
|--------|------|
| Физика игрока, враги, боссы, генерация уровней | `assets/game.js` |
| Карта мира, узлы, дороги | `assets/worldmap.js` |
| Меню настроек, качество графики | `assets/settings.js` |
| Сетевая игра | `assets/network.js` |
| Профиль игрока (аватар, ник, статистика, логи) | `assets/profile.js` |
| Демоверсия: что урезано и экран конца демо | `assets/demo.js` |
| Эффекты, которые враги вешают на игрока | `assets/status.js` |
| Тексты интерфейса | `assets/localisation/*.json` (через `t()`) |
| Окно, GPU, IPC, сохранение | `main.js` + `preload.js` |
| Сюжет, реплики, лор | `docs/STORY.md` + `CSCENES` в `assets/game.js` |

**Важно:** все пользовательские строки идут через `t('ключ')` и файлы
локализации. Хардкодить русский/английский текст в UI нельзя — иначе 50 языков
разъедутся.

Проверить локализацию:

```bash
node tools/loc-audit.js
```

Показывает по каждому языку: недостающие ключи, устаревшие, несовпадение `{0}`
и HTML-тегов, и сколько строк ещё на английском. `--keys` сверяет ключи в коде
с `en.json`, `--untranslated` выводит весь непереведённый остаток,
`--fix` удаляет ключи, которых нет в `en.json`.

## Сборка

```bash
node build/set-version.js 1.0.2   # проставить версию
node build/set-edition.js full    # редакция: full | demo
npm run build:steam               # .exe
npm run build:html                # веб
npm run build                     # обе
```

Или просто `build/build.bat` — меню с выбором цели (включая Android) и редакции
(полная / демо / обе). Подробности: `BUILD_GUIDE.md`.

## Частые проблемы

### Игра запускается, но экран чёрный
Смотри `byte-blaster-log.txt` рядом с .exe, строку `[render] tier N`.
Запусти с `--safe-mode` — включится софтверный рендеринг. Подробный разбор
причины (и почему это происходило раньше) — в `BUGS.md`, раздел CR-1.

### Игра не стартует, окно пустое
Последний `[checkpoint]` в логе показывает, на каком скрипте всё встало.
В самой игре при ошибке скрипта появляется красная панель с текстом ошибки.

### npm start выдаёт ошибку
Удали `node_modules` и запусти `npm install` заново.

### Билд слишком большой
`app.asar` должен весить ~7 МБ. Если увидел сотни мегабайт — потерялся список
исключений в `build-steam.js` (см. `BUILD_GUIDE.md`).

### Steam API не работает
1. Steam-клиент должен быть запущен
2. Нужен `steam_appid.txt` с реальным App ID
3. Нужен установленный `greenworks`

Пока App ID нет, игра просто пишет в лог «running without Steam» и работает
дальше — это нормально.
