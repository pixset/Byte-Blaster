# 🎮 Подготовка Byte Blaster к публикации в Steam

## Шаг 1: Регистрация в Steamworks

### 1.1 Создание аккаунта
1. Перейти на https://partner.steamgames.com/
2. Войти через Steam аккаунт
3. Принять соглашение Steamworks

### 1.2 Оплата Steam Direct Fee
- **Стоимость:** $100 USD (возвращается после $1000 выручки)
- **Способы оплаты:** PayPal, кредитная карта, банковский перевод
- **Срок обработки:** 1-3 рабочих дня

### 1.3 Заполнение налоговой информации
- Форма W-8BEN (для не-резидентов США)
- Или W-9 (для резидентов США)
- Банковские реквизиты для выплат

---

## Шаг 2: Создание App ID

### 2.1 Создать новое приложение
1. В Steamworks Dashboard → "Apps & Packages"
2. Нажать "Create New App"
3. Выбрать тип: **Game**
4. Название: **Byte Blaster**
5. Получить **App ID** (например, 123456)

### 2.2 Сохранить App ID
Записать App ID - он понадобится для:
- Настройки greenworks
- Загрузки билдов
- Тестирования

---

## Шаг 3: Настройка greenworks

### 3.1 Установка greenworks
```bash
cd "Byte Blaster (Steam)"
npm install greenworks --save
```

### 3.2 Скачать Steamworks SDK
1. Скачать с https://partner.steamgames.com/
2. Распаковать в папку проекта
3. Скопировать `steam_api.dll` (Windows) в корень проекта

### 3.3 Создать steam_appid.txt
Создать файл `steam_appid.txt` в корне проекта:
```
123456
```
(Заменить 123456 на ваш App ID)

### 3.4 Обновить main.js
Раскомментировать и настроить Steam API код в `main.js`

---

## Шаг 4: Настройка достижений в Steamworks

### 4.1 Перейти в раздел Achievements
1. Steamworks Dashboard → Ваше приложение
2. "Stats & Achievements" → "Achievements"

### 4.2 Добавить достижения
Для каждого достижения из `ACHIEVEMENTS.md`:

**Пример:**
- **API Name:** `achievement_world_0`
- **Display Name:** Cyber Rookie
- **Description:** Complete the first 10 levels (Cyber City)
- **Icon:** Загрузить 64x64 PNG (обычное состояние)
- **Icon (Achieved):** Загрузить 64x64 PNG (разблокированное)
- **Hidden:** No
- **Progress:** 0 (для обычных) или 10 (для прогрессивных)

### 4.3 Опубликовать изменения
Нажать "Publish" после добавления всех достижений

---

## Шаг 5: Настройка облачных сохранений

### 5.1 Включить Steam Cloud
1. Steamworks Dashboard → "Cloud"
2. Enable Steam Cloud: **Yes**
3. Quota per user: **10 MB** (достаточно для сохранений)

### 5.2 Настроить файлы
Добавить паттерны файлов для синхронизации:
```
saves/*.json
progress/*.dat
```

## Шаг 6: Подготовка билда

### 6.1 Собрать .exe
```bash
npm run build:win
```

Результат в папке `dist/`

### 6.2 Тестирование локально
1. Запустить Steam клиент
2. Убедиться что `steam_appid.txt` в корне
3. Запустить `Byte Blaster.exe`
4. Проверить что Steam оверлей работает (Shift+Tab)

### 6.3 Проверить достижения
Разблокировать тестовое достижение и проверить в Steam

## Шаг 7: Загрузка билда в Steam

### 7.1 Установить SteamCMD
1. Скачать с https://steamcdn-a.akamaihd.net/client/installer/steamcmd.zip
2. Распаковать в отдельную папку
3. Запустить `steamcmd.exe`

### 7.2 Создать скрипт загрузки
Создать `app_build_123456.vdf`:
```vdf
"AppBuild"
{
  "AppID" "123456"  // Ваш App ID
  "Desc" "Byte Blaster v1.0"
  "BuildOutput" "C:\\output\\"
  "ContentRoot" "C:\\Byte Blaster (Steam)\\dist\\"
  "SetLive" "default"
  
  "Depots"
  {
    "123457"  // Depot ID (App ID + 1)
    {
      "FileMapping"
      {
        "LocalPath" "*"
        "DepotPath" "."
        "Recursive" "1"
      }
    }
  }
}
```

### 7.3 Загрузить билд
```bash
steamcmd +login your_username +run_app_build app_build_123456.vdf +quit
```

### 7.4 Проверить билд
1. Steamworks Dashboard → "Builds"
2. Найти загруженный билд
3. Установить как "default" branch

### 8.2 Графические материалы

#### Требуемые изображения:

1. **Header Capsule** (460x215 px)
   - Главное изображение в магазине
   - Формат: JPG или PNG
   - Логотип + ключевой арт

2. **Small Capsule** (231x87 px)
   - Миниатюра в списках
   - Формат: JPG или PNG

3. **Main Capsule** (616x353 px)
   - Большая капсула на главной странице
   - Формат: JPG или PNG

4. **Library Capsule** (600x900 px)
   - Вертикальная обложка для библиотеки
   - Формат: JPG или PNG

5. **Library Hero** (3840x1240 px)
   - Фоновое изображение в библиотеке
   - Формат: JPG
   - Можно использовать размытый скриншот

6. **Library Logo** (PNG с прозрачностью)
   - Логотип для библиотеки
   - Рекомендуемый размер: 1280x720 px

7. **Скриншоты** (минимум 5)
   - Рекомендуемое разрешение: 1920x1080 или 1280x720
   - Формат: JPG или PNG
   - Показать разные миры и геймплей

8. **Трейлер** (опционально, но рекомендуется)
   - Длительность: 30-60 секунд
   - Формат: MP4, WebM
   - Показать геймплей, боссов, особенности

## Шаг 10: Публикация

### 10.1 Подготовка к релизу
1. Заполнить все обязательные поля Store Page
2. Загрузить все графические материалы
3. Установить цену
4. Выбрать дату релиза (минимум 2 недели от подачи)

### 10.2 Подать на проверку
1. Steamworks Dashboard → "Review"
2. Проверить все предупреждения
3. Нажать "Submit for Review"

### 10.3 Ожидание проверки
- **Срок:** 3-5 рабочих дней
- **Возможные проблемы:**
  - Недостающие материалы
  - Проблемы с билдом
  - Нарушение правил Steam

### 10.4 После одобрения
1. Установить точную дату релиза
2. Подготовить маркетинговые материалы
3. Анонсировать в соцсетях
4. Создать пресс-кит

### 10.5 День релиза
1. Проверить что билд активен
2. Мониторить отзывы
3. Быстро реагировать на баги
4. Общаться с игроками
