## 🏆 Новая система достижений

### Особенности:
- **45 достижений** в 8 категориях
- **Красивые уведомления** при разблокировке
- **Меню достижений** с полным списком
- **Локализация** на русский и английский
- **Редкость достижений** (от 0.3% до 85%)
- **Секретные достижения** (скрыты до разблокировки)
- **Автосохранение** в localStorage

### Категории достижений:

1. **Story Progress (10)** - За прохождение миров
   - 🏙 Cyber Rookie → 🔱 Fortress Conqueror

2. **Boss Achievements (3)** - За победу над боссами
   - ⚔ Boss Slayer I, II, III

3. **Skill Achievements (8)** - За мастерство
   - 💯 Perfect Run, Perfectionist
   - ⏱ Speedrunner
   - 🎯 Sharpshooter
   - 👟 Stomper
   - 💰 Coin Collector, Treasure Hunter, Millionaire

4. **Survival Achievements (5)** - За выживание
   - ❤ Survivor, Immortal
   - 💀 Hardcore Hero, Master, Legend

5. **Secret Achievements (5)** - Секретные
   - 🔓 Code Breaker
   - 🎮 Retro Gamer
   - 🎵 Music Lover
   - 📖 Lore Master
   - ⭐ Star Power

6. **Exploration Achievements (3)** - За исследование
   - 🗺 Explorer
   - 🏅 Completionist, True Master

7. **Infinite Mode Achievements (6)** - За бесконечный режим
   - ♾ Infinite Beginner, Master, Legend
   - 🏆 High Scorer, Score Master, Score Legend

### Как открыть меню достижений:
1. Главное меню → кнопка "🏆 ACHIEVEMENTS"
2. Или через код: `window.Achievements.showMenu()`

### API для разработчиков:

```javascript
// Разблокировать достижение
window.Achievements.unlock('achievement_world_0');

// Проверить разблокировано ли
window.Achievements.isUnlocked('achievement_world_0');

// Показать меню
window.Achievements.showMenu();

// Получить все достижения
window.Achievements.getAll();

// Получить разблокированные
window.Achievements.getUnlocked();
```

## 🎮 Как протестировать

1. Запустить игру: `npm start`
2. В главном меню нажать "🏆 ACHIEVEMENTS"
3. Использовать чит-код "UNLOCK" для разблокировки всех уровней
4. Пройти уровень и вернуться на карту - новые уровни появятся
